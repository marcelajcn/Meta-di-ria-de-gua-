# Meta-di-ria-de-gua-
💧 Define uma meta diária de água. 🥤 Escolhe quanto bebeu — 200 ml, 300 ml, 500 ml etc. 📊 Vê uma barrinha/progresso do quanto já tomou. ⏰ Recebe lembretes para beber água. 🎉 Quando completa a meta, aparece uma mensagem comemorando. 💾 O progresso fica salvo no navegador, mesmo se fechar a página.
